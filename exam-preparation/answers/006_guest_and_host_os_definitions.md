# Дайте определения Гостевой и Материнской ОС

## Краткий ответ
Материнская (хостовая) ОС — это операционная система, установленная непосредственно на физическое оборудование, которая предоставляет ресурсы и управляет гипервизором типа 2. Гостевая ОС — это операционная система, работающая внутри виртуальной машины, которая изолирована от физического оборудования и взаимодействует с виртуализированными ресурсами через гипервизор.

## Развёрнутый ответ

### Материнская ОС (Host OS, Хостовая ОС)

**Определение:**
Материнская операционная система — это основная операционная система, установленная непосредственно на физическое оборудование компьютера. Она имеет прямой доступ к аппаратным ресурсам и отвечает за управление физическим оборудованием.

**Характеристики материнской ОС:**

1. **Прямой доступ к оборудованию**
   - Непосредственное взаимодействие с процессором, памятью, дисками
   - Полный контроль над всеми физическими устройствами
   - Управление системными ресурсами

2. **Базовая платформа**
   - Служит основой для работы гипервизора типа 2
   - Предоставляет API и системные вызовы
   - Обеспечивает драйверы устройств

3. **Распределение ресурсов**
   - Распределяет ресурсы между собственными процессами и виртуальными машинами
   - Управляет планированием задач
   - Контролирует доступ к устройствам

4. **Примеры использования**
   - Windows 10/11 с установленным VirtualBox или VMware Workstation
   - Linux с установленным KVM (в режиме hosted)
   - macOS с Parallels Desktop

**Важное замечание:**
В случае гипервизора типа 1 (bare-metal) понятие материнской ОС не применяется, поскольку гипервизор устанавливается непосредственно на оборудование без промежуточной операционной системы.

### Гостевая ОС (Guest OS)

**Определение:**
Гостевая операционная система — это операционная система, работающая внутри виртуальной машины. Она изолирована от физического оборудования и взаимодействует с виртуализированными ресурсами, предоставляемыми гипервизором.

**Характеристики гостевой ОС:**

1. **Виртуализированное окружение**
   - Работает в изолированной виртуальной машине
   - Не имеет прямого доступа к физическому оборудованию
   - Взаимодействует с виртуальными устройствами

2. **Изоляция**
   - Изолирована от материнской ОС и других гостевых ОС
   - Собственное виртуальное адресное пространство
   - Независимый жизненный цикл

3. **Иллюзия полного контроля**
   - "Видит" виртуализированное оборудование как реальное
   - Может быть не осведомлена о виртуализации (в случае полной виртуализации)
   - Работает так, будто установлена на физическом оборудовании

4. **Множественность**
   - На одном физическом сервере может работать множество гостевых ОС
   - Различные типы и версии ОС могут сосуществовать
   - Независимое управление каждой VM

5. **Зависимость от гипервизора**
   - Все запросы к "оборудованию" перехватываются гипервизором
   - Гипервизор транслирует или эмулирует необходимые операции
   - Ресурсы выделяются гипервизором

### Взаимосвязь материнской и гостевой ОС

**Для гипервизора типа 2 (Hosted):**
```
┌─────────────────────────────────────┐
│     Гостевая ОС (Guest OS)          │
│  (Linux, Windows, macOS и т.д.)     │
├─────────────────────────────────────┤
│     Виртуальная машина (VM)         │
├─────────────────────────────────────┤
│  Гипервизор типа 2 (VirtualBox)     │
├─────────────────────────────────────┤
│  Материнская ОС (Host OS)           │
│      (Windows, Linux, macOS)        │
├─────────────────────────────────────┤
│  Физическое оборудование            │
└─────────────────────────────────────┘
```

**Для гипервизора типа 1 (Bare-Metal):**
```
┌─────────────────────────────────────┐
│     Гостевая ОС (Guest OS)          │
│  (Linux, Windows, macOS и т.д.)     │
├─────────────────────────────────────┤
│     Виртуальная машина (VM)         │
├─────────────────────────────────────┤
│  Гипервизор типа 1 (ESXi, Hyper-V)  │
│  (Материнской ОС нет)               │
├─────────────────────────────────────┤
│  Физическое оборудование            │
└─────────────────────────────────────┘
```

### Примеры конфигураций

**Пример 1: Разработка**
- Материнская ОС: Windows 11
- Гипервизор: VMware Workstation
- Гостевые ОС: Ubuntu Linux, Windows Server, CentOS

**Пример 2: Тестирование**
- Материнская ОС: macOS
- Гипервизор: Parallels Desktop
- Гостевые ОС: Windows 10, Windows 11, различные дистрибутивы Linux

**Пример 3: Серверная инфраструктура**
- Материнская ОС: отсутствует
- Гипервизор: VMware ESXi (тип 1)
- Гостевые ОС: множество серверных ОС для разных сервисов

# Опишите политики перезапуска контейнера

## Краткий ответ

Docker предоставляет четыре политики перезапуска контейнеров: `no` (без перезапуска), `on-failure` (при ошибке с возможностью ограничения попыток), `always` (всегда перезапускать) и `unless-stopped` (всегда, кроме явной остановки). Политики задаются флагом `--restart` и определяют поведение контейнера при падении или перезагрузке Docker daemon.

## Развёрнутый ответ

Docker предоставляет механизм автоматического перезапуска контейнеров через политики перезапуска (restart policies), которые определяют, как Docker должен обрабатывать остановку контейнера.

### Доступные политики перезапуска

**1. no (по умолчанию)**
- Контейнер никогда не перезапускается автоматически
- Используется для задач, которые должны выполниться один раз
- Пример: `docker run --restart=no nginx`

**2. on-failure[:max-retries]**
- Контейнер перезапускается только при ненулевом коде завершения
- Можно ограничить количество попыток перезапуска
- Полезно для приложений, которые могут восстановиться после ошибки
- Пример: `docker run --restart=on-failure:3 nginx` (максимум 3 попытки)
- При достижении лимита попыток контейнер остаётся остановленным

**3. always**
- Контейнер всегда перезапускается при остановке
- Перезапускается даже при явной остановке командой `docker stop`
- Автоматически запускается при старте Docker daemon
- Используется для критических сервисов, которые должны работать постоянно
- Пример: `docker run --restart=always nginx`

**4. unless-stopped**
- Контейнер перезапускается при любой остановке, кроме явной командой `docker stop`
- При перезагрузке Docker daemon контейнер запускается только если не был остановлен вручную
- Более предсказуемое поведение по сравнению с `always`
- Пример: `docker run --restart=unless-stopped nginx`

### Изменение политики перезапуска

Политику можно изменить для запущенного контейнера:
```bash
docker update --restart=unless-stopped <container_id>
```

### Проверка текущей политики

```bash
docker inspect -f "{{.HostConfig.RestartPolicy}}" <container_id>
```

### Взаимодействие с Docker daemon

При перезапуске Docker daemon:
- Контейнеры с `no` и `on-failure` остаются остановленными
- Контейнеры с `always` всегда запускаются
- Контейнеры с `unless-stopped` запускаются, если не были остановлены вручную

### Практические рекомендации

- Для production-сервисов используйте `unless-stopped` или `always`
- Для batch-задач и тестирования используйте `no`
- Для процессов с временными сбоями используйте `on-failure` с ограничением попыток
- В Docker Compose политика задаётся в разделе `restart:`

### Мониторинг перезапусков

Docker отслеживает количество перезапусков:
```bash
docker inspect -f "{{.RestartCount}}" <container_id>
```

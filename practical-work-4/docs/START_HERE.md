# 🎯 НАЧНИТЕ ЗДЕСЬ - Практическая работа 4

## 🚀 Самый быстрый способ запустить и проверить ВСЁ

```bash
# Из корня проекта
cd practical-work-4
./scripts/full-validation.sh

# Или из любой директории
/path/to/practical-work-4/scripts/full-validation.sh
```

**Один скрипт проверяет все 10 критериев на 2 балла!**

- ⏱️ Время выполнения: 3-5 минут (или 30 секунд без Docker)
- ✅ Выполняет статические проверки кода и конфигурации
- ✅ Автоматически запускает все 13 контейнеров (если Docker запущен)
- ✅ Проверяет CRUD операции
- ✅ Тестирует экспорт логов в CSV
- ✅ Проверяет все системы мониторинга
- ✅ Показывает процент готовности

**Примечание:** 
- По умолчанию скрипт **автоматически запустит Colima**, если Docker не запущен
- Для отключения автозапуска: `START_COLIMA=false ./scripts/full-validation.sh`
- Для автоостановки Colima после тестов: `STOP_COLIMA=true ./scripts/full-validation.sh`

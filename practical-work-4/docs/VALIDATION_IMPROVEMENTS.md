# Улучшения скрипта валидации (full-validation.sh)

## 📋 Что было исправлено

### 1. **Исправлена проверка доступности сервисов**
- ❌ **Было**: URL парсились неправильно из-за двойного слэша `//localhost`
- ✅ **Стало**: Используется разделитель `|` вместо `:` для корректного парсинга

### 2. **Улучшена функция `wait_for_service()`**
- Добавлена проверка HTTP кодов (200, 301, 302)
- Добавлен таймаут для каждого запроса (10 секунд)
- Добавлено логирование HTTP кодов и ответов серверов
- Сокращено время ожидания между попытками (10 сек вместо 30)

### 3. **Улучшена функция `check_web_service()`**
- Добавлена возможность повторных попыток (retries)
- GrayLog: 5 попыток (требует больше времени для запуска)
- Zabbix: 3 попытки
- Grafana: 2 попытки
- Добавлено логирование HTTP кодов и ответов

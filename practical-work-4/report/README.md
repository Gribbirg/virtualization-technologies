## Конвертация в Word

Для конвертации отчета в формат Word (.docx) используйте следующую команду:

```bash
cd /Users/alexgribkov/study/virtualization-technologies/practical-work-4/report

pandoc ПВКСП_Отчет4_ГрибковАС_ИКБО-16-22.md \
  -o ПВКСП_Отчет4_ГрибковАС_ИКБО-16-22.docx \
  --reference-doc=../../common/style_source.docx
```

### Требования

- Установленный Pandoc (версия 2.0 или выше)
- Файл `common/style_source.docx` с определенными стилями

### Проверка после конвертации

После конвертации откройте документ в Microsoft Word или LibreOffice и проверьте:

1. **Стили заголовков:**
   - Heading 1 применен к основным разделам (ЦЕЛЬ РАБОТЫ, ХОД РАБОТЫ, ВЫВОД и т.д.)
   - Heading 2 применен к подразделам (Разработка моделей данных, Реализация CRUD контроллеров и т.д.)

2. **Стили кода:**
   - "Listing" применен к подписям листингов
   - "Code" применен к блокам кода

3. **Стили изображений:**
   - "Picture" применен к placeholders изображений
   - "Picture name" применен к подписям изображений

4. **Содержание:**
   - "TOCHeading" применен к слову "СОДЕРЖАНИЕ"
   - "Content" применен к элементам оглавления

5. **Автоматическая нумерация:**
   - Проверьте, что Word автоматически добавил префиксы "Рисунок X.", "Таблица X.", "Листинг X." к соответствующим подписям

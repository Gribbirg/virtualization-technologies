# Port Configuration Changes

## Изменения портов для избежания конфликтов с практической работой 8

### Новая конфигурация портов (Практическая работа 6)

| Сервис | Kubernetes Port | Localhost Port (старый) | Localhost Port (новый) |
|--------|----------------|------------------------|----------------------|
| Frontend (Journal Server) | 8080 | 8083 | **8085** |
| FileServer (Static files) | 80 | 8081 | **8086** |
| Redis | 6379 | 6379 | 6379 (без изменений) |

### Причина изменений

Порты 8081 и 8083 на localhost конфликтуют с портами практической работы 8:
- **8081**: Auth Service (практическая работа 8)
- **8083**: Notification Service (практическая работа 8)

### Обновленные файлы

1. `scripts/port-forward-all.sh` - основной скрипт для проброса портов
2. `README.md` - документация проекта
3. `docs/QUICK_START.md` - быстрый старт
4. `docs/DEMO_GUIDE.md` - гид для демонстрации
5. `test/run_tests.sh` - тестовый скрипт
6. `test/API_TESTING.md` - документация по тестированию API

### Как использовать

Теперь для доступа к сервисам используйте:

```bash
# Запустить проброс портов
./scripts/port-forward-all.sh

# Тестировать Frontend API
curl http://localhost:8085/api

# Открыть FileServer в браузере
open http://localhost:8086/

# Redis (без изменений)
redis-cli -h localhost -p 6379
```

### Совместимость

Теперь практические работы 6 и 8 могут работать одновременно без конфликтов портов.

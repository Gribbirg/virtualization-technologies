Что будет установлено:
----------------------

ИНФРАСТРУКТУРА (через Helm):
- PostgreSQL x3 (bitnami/postgresql) - для каждого сервиса
- Redis (bitnami/redis) - хранение JWT токенов
- Kafka (bitnami/kafka) - событийная шина
- MongoDB (bitnami/mongodb) - для Graylog
- Elasticsearch (bitnami/elasticsearch) - для Graylog
- Prometheus (prometheus-community/prometheus) - метрики
- Grafana (grafana/grafana) - визуализация
- Jaeger (jaegertracing/jaeger) - трассировка

ИНФРАСТРУКТУРА (через kubectl):
- Graylog - логирование (HTTP method, URL, IP)
- KrakenD - API Gateway

МИКРОСЕРВИСЫ (через Helm):
- Auth Service - аутентификация
- Task Service - управление задачами
- Notification Service - уведомления

Соответствие требованиям задания:

✅ Сервис авторизации с Redis

✅ Prometheus + Grafana

Как запустить:
-------------

1. Развернуть систему:
   ./deploy-all.sh

2. Запустить port forwarding (в отдельном терминале):
   ./port-forward.sh

3. Протестировать:
   ./test-system.sh

4. Проверить статус:
   ./status.sh

5. Очистить:
   ./cleanup.sh

Доступ к сервисам:
-----------------

После запуска port-forward.sh:

- KrakenD (Gateway): http://localhost:8080
- Auth Service: http://localhost:8081
- Task Service: http://localhost:8082
- Notification Service: http://localhost:8083
- Graylog: http://localhost:9000 (admin/admin)
- Grafana: http://localhost:3000 (admin/admin)
- Prometheus: http://localhost:9090
- Jaeger: http://localhost:16686
